# prompt_store/custom_agents

**Currently empty.** Reserved for prompts belonging to specific custom agents.

The instructions that compose a course Teaching Assistant are in
[../core_agent_prompts/](../core_agent_prompts) — that is the set loaded at runtime, and
it is where teaching behaviour is edited.

Related: [../agents/](../agents) holds small single-purpose task prompts, and
[../research_agents/](../research_agents) holds the research agent prompts.

Git does not track empty directories, so this folder does not survive a clone without this
file.
